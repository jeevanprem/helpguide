Bubble Sort
Sorting O(n²)
▼

🧠 Core Concept

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The largest unsorted element "bubbles up" to its correct position in each pass.

  • In each pass, the largest remaining element reaches its final position.
  • The outer loop shrinks by 1 each iteration (already sorted elements at the end).
  • Simple but inefficient for large datasets.

⭐ Key Logic

Compare arr[j] with arr[j+1] — if left > right, swap them.

📋 Algorithm Steps

  1. Start with the full array (outer loop i from n down to 1)
  2. For each element j from 0 to i, compare arr[j] and arr[j+1]
  3. If arr[j] > arr[j+1], swap them
  4. After each pass, the largest element is at the end
  5. Repeat until no swaps are needed

💻 Complete Code

bubblesort.c 
#include <stdio.h>

int main() {
    printf("bubble sort\n");

    /* Initialize array with unsorted values */
    int arr1[5] = {4, 3, 5, 2, 1};
    int temp;              /* Temporary variable for swapping */
    int n = 5;             /* Number of elements */
    int i, j;

    /* Outer loop: shrink the unsorted portion from n down to 1
       After each pass, the largest element bubbles to the end */
    for (int i = n; i > 1; i--) {

        /* Inner loop: compare adjacent elements from start to i */
        for (int j = 0; j < i; j++) {

            /* If current element is greater than next, swap them */
            if (arr1[j] > arr1[j + 1]) {
                temp = arr1[j];
                arr1[j] = arr1[j + 1];
                arr1[j + 1] = temp;
            }
        }
    }

    /* Print the sorted array */
    for (int i = 0; i < n; i++) {
        printf("%d ", arr1[i]);
    }

    return 0;
}

Merge Sort
Sorting O(n log n)
▼

🧠 Core Concept

Merge Sort uses the Divide and Conquer strategy: DIVIDE → SORT → MERGE.

  • Divide the array into two halves
  • Recursively sort each half
  • Merge the two sorted halves back together
  • Uses a temporary array during the merge step

⭐ Hardest Part to Remember — The Merge Loop

while (i <= mid && j <= right) — compare elements from both halves and pick the smaller one. Then copy remaining elements from whichever half isn't exhausted.

📋 Algorithm Steps

  1. If left < right, find mid = (left + right) / 2
  2. mergeSort(left half) — left to mid
  3. mergeSort(right half) — mid+1 to right
  4. merge() — combine both sorted halves using a temp array
  5. Copy merged result back into original array

💻 Complete Code

mergesort.c 
#include <stdio.h>

/* ─── merge() ───────────────────────────────────────────────
   Merges two sorted sub-arrays: arr[left..mid] and arr[mid+1..right]
   Uses a temporary array to hold the merged result.
   ────────────────────────────────────────────────────────── */
void merge(int arr[], int left, int mid, int right) {

    int i = left;              /* Pointer for left sub-array */
    int j = mid + 1;           /* Pointer for right sub-array */
    int k = 0;                 /* Pointer for temp array */

    int temp[right - left + 1]; /* Temporary array to hold merged result */

    /* Compare elements from both halves and pick the smaller one */
    while (i <= mid && j <= right) {

        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];  /* Left element is smaller */
        else
            temp[k++] = arr[j++];  /* Right element is smaller */
    }

    /* Copy any remaining elements from left half */
    while (i <= mid)
        temp[k++] = arr[i++];

    /* Copy any remaining elements from right half */
    while (j <= right)
        temp[k++] = arr[j++];

    /* Copy merged elements back into the original array */
    for (i = left, k = 0; i <= right; i++, k++)
        arr[i] = temp[k];
}

/* ─── mergeSort() ───────────────────────────────────────────
   Recursively divides the array in half, sorts each half,
   then merges them back together.
   ────────────────────────────────────────────────────────── */
void mergeSort(int arr[], int left, int right) {

    if (left < right) {

        int mid = (left + right) / 2;  /* Find the midpoint */

        mergeSort(arr, left, mid);       /* Sort left half */

        mergeSort(arr, mid + 1, right);  /* Sort right half */

        merge(arr, left, mid, right);    /* Merge both sorted halves */
    }
}

int main() {

    int n;

    printf("Enter size: ");
    scanf("%d", &n);

    int arr[n];

    printf("Enter elements:\n");

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    mergeSort(arr, 0, n - 1);       /* Sort the entire array */

    printf("Sorted array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

Quick Sort
Sorting O(n log n)
▼

🧠 Core Concept

Quick Sort picks a pivot element and partitions the array so that all elements smaller than pivot go left, and all larger go right. Then recursively sort both sides.

  • Pivot = last element (arr[high])
  • i = boundary of "smaller" elements (starts at low - 1)
  • j = scanner that checks every element
  • After partitioning, pivot is placed at its correct final position

⭐ Key Parts to Remember

i = low - 1 — boundary tracker
if (arr[j] < pivot) { i++; swap; } — move smaller elements left
swap(&arr[i+1], &arr[high]) — place pivot at correct position
return i + 1 — return pivot's final position

📋 Algorithm Steps

  1. Choose last element as pivot
  2. Partition: scan with j, use i to track smaller-element boundary
  3. Get pivot's final position p
  4. Recursively sort left (low to p-1) and right (p+1 to high)

💻 Complete Code

QuickSort.c 
#include <stdio.h>

/* ─── swap() ─────────────────────────────────────────────
   Swaps two integers using pointers.
   ────────────────────────────────────────────────────────── */
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

/* ─── partition() ────────────────────────────────────────
   Chooses the last element as pivot.
   Rearranges array so all elements < pivot go left,
   all elements > pivot go right.
   Returns the final index of the pivot.
   ────────────────────────────────────────────────────────── */
int partition(int arr[], int low, int high) {

    int pivot = arr[high];   /* Choose last element as pivot */

    int i = low - 1;         /* i = boundary of smaller elements
                                Starts BEFORE the array segment */

    /* j scans from low to high-1 */
    for (int j = low; j < high; j++) {

        /* If current element is smaller than pivot,
           move it to the "smaller" side */
        if (arr[j] < pivot) {
            i++;                        /* Expand smaller boundary */
            swap(&arr[i], &arr[j]);  /* Swap element into position */
        }
    }

    /* Place pivot at its correct final position (i+1) */
    swap(&arr[i + 1], &arr[high]);

    return i + 1;  /* Return pivot's final index */
}

/* ─── quickSort() ────────────────────────────────────────
   Main recursive QuickSort function.
   Partitions, then sorts left and right sub-arrays.
   ────────────────────────────────────────────────────────── */
void quickSort(int arr[], int low, int high) {

    if (low < high) {

        int p = partition(arr, low, high);  /* Get pivot position */

        quickSort(arr, low, p - 1);         /* Sort left of pivot */

        quickSort(arr, p + 1, high);         /* Sort right of pivot */
    }
}

int main() {
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int arr[n];

    printf("Enter elements:\n");

    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    quickSort(arr, 0, n - 1);  /* Sort the entire array */

    printf("Sorted array: ");

    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    return 0;
}

Heap Sort
Sorting O(n log n)
▼

🧠 Core Concept

Heap Sort builds a Max Heap from the array, then repeatedly extracts the maximum element.

  • Max Heap property: Parent ≥ children
  • For index i: left = 2*i + 1, right = 2*i + 2
  • BUILD MAX HEAP → Swap root with last → Reduce heap size → Heapify → Repeat

⭐ Most Important — heapify() Logic

largest = i;
if (left < n && arr[left] > arr[largest]) largest = left;
if (right < n && arr[right] > arr[largest]) largest = right;
if (largest != i) { swap; heapify(arr, n, largest); }

📋 Algorithm Steps

  1. Build Max Heap — heapify from n/2 - 1 down to 0
  2. Swap root (max) with the last element
  3. Reduce heap size by 1
  4. Heapify the root to restore Max Heap property
  5. Repeat until heap size is 1

💻 Complete Code

HeapSort.c 
#include <stdio.h>

/* ─── swap() ─────────────────────────────────────────────
   Swaps two integers using pointers.
   ────────────────────────────────────────────────────────── */
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

/* ─── heapify() ──────────────────────────────────────────
   Ensures the Max Heap property for the subtree rooted at index i.
   - Compares node i with its left (2*i+1) and right (2*i+2) children
   - If a child is larger, swap with the largest child
   - Recursively heapify the affected subtree
   ────────────────────────────────────────────────────────── */
void heapify(int arr[], int n, int i) {

    int largest = i;               /* Assume root is largest */

    int left = 2 * i + 1;          /* Left child index */
    int right = 2 * i + 2;         /* Right child index */

    /* If left child exists and is greater than root */
    if (left < n && arr[left] > arr[largest])
        largest = left;

    /* If right child exists and is greater than current largest */
    if (right < n && arr[right] > arr[largest])
        largest = right;

    /* If largest is not the root, swap and continue heapifying */
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);     /* Recursively fix the subtree */
    }
}

/* ─── heapSort() ─────────────────────────────────────────
   1. Builds a Max Heap from the array
   2. Extracts elements one by one from the heap
   ────────────────────────────────────────────────────────── */
void heapSort(int arr[], int n) {

    /* Step 1: Build Max Heap
       Start from the last non-leaf node (n/2 - 1) and heapify each */
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    /* Step 2: Extract elements from heap
       Swap root (max) with last element, shrink heap, re-heapify */
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);   /* Move current max to end */
        heapify(arr, i, 0);       /* Heapify reduced heap */
    }
}

int main() {
    int n;

    printf("Enter size: ");
    scanf("%d", &n);

    int arr[n];

    printf("Enter elements:\n");

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    heapSort(arr, n);           /* Perform Heap Sort */

    printf("Sorted array:\n");

    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);

    return 0;
}

DFS — Depth First Search
Graph O(V + E)
▼

🧠 Core Concept

DFS goes as deep as possible before backtracking. It uses recursion (implicit stack).

  • Visit a vertex → Mark it visited → Check all neighbours
  • If neighbour is connected AND unvisited → recursively DFS on it
  • Uses an adjacency matrix and a visited[] array

⭐ Most Important Line — The Recursive Call

if (graph[v][i] == 1 && visited[i] == 0) → DFS(i, n);
This is the heart of DFS: visit every connected, unvisited neighbour.

📋 Algorithm Steps

  1. Print/visit the current vertex v
  2. Mark visited[v] = 1
  3. For each vertex i from 0 to n-1:
  4. If graph[v][i] == 1 (connected) AND visited[i] == 0 (unvisited) → DFS(i, n)
  5. Backtrack when no unvisited neighbours remain

💻 Complete Code

dfs.c 
#include <stdio.h>

#define MAX 100

/* ─── Global arrays ──────────────────────────────────────
   graph[][] = adjacency matrix (1 = edge exists)
   visited[] = tracks which vertices have been visited
   ────────────────────────────────────────────────────────── */
int graph[MAX][MAX];
int visited[MAX];

/* ─── DFS() ──────────────────────────────────────────────
   Recursive Depth First Search.
   v = current vertex, n = total number of vertices
   ────────────────────────────────────────────────────────── */
void DFS(int v, int n) {

    printf("%d ", v);       /* Step 1: Visit (print) the vertex */
    visited[v] = 1;          /* Step 2: Mark it as visited */

    /* Step 3: Check ALL vertices to find neighbours */
    for (int i = 0; i < n; i++) {

        /* If there's an edge (connected) AND not yet visited */
        if (graph[v][i] == 1 && visited[i] == 0) {
            DFS(i, n);       /* ⭐ Recurse into the unvisited neighbour */
        }
    }
}

int main() {
    int n;
    int start;

    printf("Enter number of vertices: ");
    scanf("%d", &n);

    printf("Enter adjacency matrix:\n");

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            scanf("%d", &graph[i][j]);
        }
    }

    /* Initialize all vertices as unvisited */
    for (int i = 0; i < n; i++) {
        visited[i] = 0;
    }

    printf("Enter starting vertex: ");
    scanf("%d", &start);

    printf("DFS Traversal: ");
    DFS(start, n);

    return 0;
}

Dijkstra's Algorithm
Graph O(V²)
▼

🧠 Core Concept

Finds the shortest path from one source vertex to every other vertex in a weighted graph. Works only with non-negative edge weights.

  • Memory trick: DISTANCE → MINIMUM → FIX → RELAX
  • Start all distances = ∞, source distance = 0
  • Repeatedly pick the unvisited vertex with minimum distance
  • Relax all its neighbours (update shorter paths)

⭐ Relaxation — Most Important Line

if (dist[u] + graph[u][v] < dist[v])
    dist[v] = dist[u] + graph[u][v];

📋 Algorithm Steps

  1. Set all distances = INT_MAX (infinity)
  2. Set source distance = 0
  3. Find the unvisited vertex u with minimum distance
  4. Mark u as visited
  5. For every neighbour v of u: if dist[u] + weight(u,v) < dist[v], update dist[v]
  6. Repeat V-1 times

💻 Complete Code

dijistra.c 
#include <stdio.h>
#include <limits.h>

#define V 5   /* Number of vertices in the graph */

/* ─── minDistance() ──────────────────────────────────────
   Finds the unvisited vertex with the smallest distance value.
   Returns the index of that vertex.
   ────────────────────────────────────────────────────────── */
int minDistance(int dist[], int visited[]) {

    int min = INT_MAX;    /* Start with infinity */
    int index = -1;

    for (int i = 0; i < V; i++) {

        /* If not visited and distance is smaller than current min */
        if (!visited[i] && dist[i] < min) {
            min = dist[i];
            index = i;
        }
    }

    return index;
}

/* ─── dijkstra() ─────────────────────────────────────────
   Computes shortest distances from 'source' to all vertices.
   Uses adjacency matrix representation.
   ────────────────────────────────────────────────────────── */
void dijkstra(int graph[V][V], int source) {

    int dist[V];            /* dist[i] = shortest distance from source to i */
    int visited[V];          /* visited[i] = 1 if vertex i is finalized */

    /* Initialize: all distances = infinity, all unvisited */
    for (int i = 0; i < V; i++) {
        dist[i] = INT_MAX;
        visited[i] = 0;
    }

    dist[source] = 0;        /* Distance from source to itself is 0 */

    /* Process V-1 vertices */
    for (int count = 0; count < V - 1; count++) {

        int u = minDistance(dist, visited); /* Pick min distance vertex */

        visited[u] = 1;                      /* Mark it as finalized */

        /* ⭐ RELAXATION: Update distances of all neighbours of u */
        for (int v = 0; v < V; v++) {

            if (!visited[v] &&                /* Not yet finalized */
                graph[u][v] &&                  /* Edge exists */
                dist[u] != INT_MAX &&            /* u is reachable */
                dist[u] + graph[u][v] < dist[v]) /* Shorter path found */
            {
                dist[v] = dist[u] + graph[u][v]; /* Update distance */
            }
        }
    }

    /* Print shortest distances */
    printf("Vertex\tDistance\n");

    for (int i = 0; i < V; i++)
        printf("%d\t%d\n", i, dist[i]);
}

int main() {

    /* Adjacency matrix (0 = no edge) */
    int graph[V][V] = {
        {0, 10, 0, 5, 0},
        {10, 0, 1, 2, 0},
        {0, 1, 0, 9, 4},
        {5, 2, 9, 0, 2},
        {0, 0, 4, 2, 0}
    };

    dijkstra(graph, 0);  /* Run Dijkstra from vertex 0 */

    return 0;
}

Kruskal's MST (Min Cost Spanning Tree)
Graph O(E log E)
▼

🧠 Core Concept

Kruskal's algorithm builds a Minimum Spanning Tree by greedily picking the smallest edges, as long as they don't create a cycle.

  • Memory trick: SORT → PICK → CHECK CYCLE
  • Uses Union-Find (Disjoint Set) data structure to detect cycles
  • Stop when V-1 edges are selected

⭐ Key Logic — Union-Find Cycle Check

if (find(parent, u) != find(parent, v)) → no cycle, include edge
union(parent, u, v) → merge the two sets

📋 Algorithm Steps

  1. Sort all edges by weight (ascending)
  2. Initialize parent[] — each vertex is its own parent
  3. Pick the smallest edge
  4. If find(u) ≠ find(v) → no cycle → include edge, union(u, v)
  5. Repeat until V-1 edges are added

💻 Complete Code

mincostspan.c 
#include <stdio.h>

/* Edge structure: stores source, destination, and weight */
struct Edge {
    int u, v, weight;
};

/* ─── find() ─────────────────────────────────────────────
   Find the root of the set that x belongs to.
   Uses PATH COMPRESSION: makes every node point directly
   to the root, flattening the tree for future lookups.
   ────────────────────────────────────────────────────────── */
int find(int parent[], int x) {
    if (parent[x] != x)
        parent[x] = find(parent, parent[x]);  /* Path compression */

    return parent[x];
}

/* ─── unionSet() ─────────────────────────────────────────
   Union by Rank: attach the shorter tree under the taller tree.
   This keeps the tree flat and find() efficient.
   ────────────────────────────────────────────────────────── */
void unionSet(int parent[], int rank[], int x, int y) {

    int rootX = find(parent, x);
    int rootY = find(parent, y);

    if (rootX != rootY) {

        /* Attach smaller-rank tree under larger-rank tree */
        if (rank[rootX] < rank[rootY])
            parent[rootX] = rootY;

        else if (rank[rootX] > rank[rootY])
            parent[rootY] = rootX;

        else {
            parent[rootY] = rootX;
            rank[rootX]++;            /* Increase rank when equal */
        }
    }
}

int main() {

    int V, E;

    printf("Enter vertices and edges: ");
    scanf("%d %d", &V, &E);

    struct Edge edges[E];

    for (int i = 0; i < E; i++) {
        printf("Enter u v weight: ");
        scanf("%d %d %d",
              &edges[i].u,
              &edges[i].v,
              &edges[i].weight);
    }

    /* Step 1: Sort edges by weight (ascending) — using bubble sort */
    for (int i = 0; i < E - 1; i++) {
        for (int j = i + 1; j < E; j++) {

            if (edges[i].weight > edges[j].weight) {
                struct Edge temp = edges[i];
                edges[i] = edges[j];
                edges[j] = temp;
            }
        }
    }

    /* Initialize Union-Find: each vertex is its own parent */
    int parent[V];
    int rank[V];

    for (int i = 0; i < V; i++) {
        parent[i] = i;     /* Each node is its own root */
        rank[i] = 0;       /* Rank starts at 0 */
    }

    int count = 0;     /* Number of edges in MST */
    int cost = 0;      /* Total cost of MST */

    printf("Edges in MST:\n");

    /* Step 2: Pick edges in order, include if no cycle */
    for (int i = 0; i < E && count < V - 1; i++) {

        int u = edges[i].u;
        int v = edges[i].v;

        /* ⭐ If u and v are in different sets → no cycle */
        if (find(parent, u) != find(parent, v)) {

            printf("%d -- %d = %d\n",
                   u, v, edges[i].weight);

            cost += edges[i].weight;

            unionSet(parent, rank, u, v);  /* Merge the two sets */

            count++;
        }
    }

    printf("Minimum cost = %d\n", cost);

    return 0;
}

Activity Selection
Greedy O(n log n)
▼

🧠 Core Concept

Select the maximum number of non-overlapping activities. Greedy rule: always pick the activity that finishes earliest.

  • Each activity has a start time and finish time
  • Sort by finish time (ascending)
  • Select first activity, then for each remaining: if start ≥ last_finish → select it

⭐ Most Important Line

if (activities[i].start >= lastFinish) → select this activity

📋 Algorithm Steps

  1. Sort activities by finish time
  2. Select the first activity (earliest finish)
  3. For each remaining activity: if its start ≥ last selected finish → include it
  4. Update lastFinish to the newly selected activity's finish time

💻 Complete Code

activity.c 
#include <stdio.h>

/* Activity structure: holds start and finish times */
struct Activity {
    int start;
    int finish;
};

int main() {
    int n;

    printf("Enter number of activities: ");
    scanf("%d", &n);

    struct Activity a[n];

    for (int i = 0; i < n; i++) {
        printf("Enter start and finish: ");
        scanf("%d %d", &a[i].start, &a[i].finish);
    }

    /* Step 1: Sort activities by finish time (ascending)
       Using selection sort for simplicity */
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {

            if (a[i].finish > a[j].finish) {
                struct Activity temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
        }
    }

    printf("Selected activities:\n");

    int lastFinish = -1;  /* Track last selected activity's finish time */

    /* Step 2: Greedily select non-overlapping activities */
    for (int i = 0; i < n; i++) {

        /* ⭐ If this activity starts after the last selected one finishes */
        if (a[i].start >= lastFinish) {
            printf("(%d, %d)\n",
                   a[i].start,
                   a[i].finish);

            lastFinish = a[i].finish;  /* Update last finish time */
        }
    }

    return 0;
}

Fractional Knapsack
Greedy O(n log n)
▼

🧠 Core Concept

Unlike 0/1 Knapsack, you can take a fraction of an item. So calculate the value/weight ratio and sort by it.

  • Calculate ratio = value / weight for each item
  • Sort items by decreasing ratio
  • Take whole items if they fit, otherwise take the fraction that fits

⭐ Key Decision Logic

if (weight[i] <= capacity) → take whole item
else { total += ratio[i] * capacity; break; } → take fraction, stop

📋 Algorithm Steps

  1. Calculate value/weight ratio for each item
  2. Sort items by decreasing ratio
  3. For each item: if whole item fits → take it; else take remaining fraction and stop

💻 Complete Code

fractionalknap.c 
#include <stdio.h>

/* Item structure: weight, value, and computed ratio */
struct Item {
    int weight;
    int value;
    float ratio;   /* value / weight — higher is better */
};

int main() {
    int n, capacity;

    printf("Enter number of items: ");
    scanf("%d", &n);

    struct Item item[n];

    for (int i = 0; i < n; i++) {
        printf("Enter weight and value: ");
        scanf("%d %d", &item[i].weight, &item[i].value);

        /* Calculate value-to-weight ratio */
        item[i].ratio =
            (float)item[i].value / item[i].weight;
    }

    printf("Enter capacity: ");
    scanf("%d", &capacity);

    /* Step 1: Sort items by DECREASING ratio (best value per weight first) */
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {

            if (item[i].ratio < item[j].ratio) {
                struct Item temp = item[i];
                item[i] = item[j];
                item[j] = temp;
            }
        }
    }

    float total = 0;  /* Total value collected */

    /* Step 2: Greedily take items (whole or fraction) */
    for (int i = 0; i < n; i++) {

        /* If the whole item fits in remaining capacity */
        if (item[i].weight <= capacity) {
            total += item[i].value;        /* Take whole item */
            capacity -= item[i].weight;     /* Reduce capacity */
        }
        else {
            /* ⭐ Take only the fraction that fits */
            total += item[i].ratio * capacity;
            break;   /* Bag is full, stop */
        }
    }

    printf("Maximum value = %.2f\n", total);

    return 0;
}

0/1 Knapsack
Dynamic Programming O(n×W)
▼

🧠 Core Concept

You have items with weight and value, and a bag with capacity W. For every item, you can take it (1) or leave it (0) — no fractions allowed.

  • dp[i][w] = maximum value using first i items with capacity w
  • Don't take → dp[i-1][w]
  • Take → value[i-1] + dp[i-1][w - weight[i-1]]
  • Answer = dp[n][W]

⭐ The DP Recurrence — Remember This!

if (weight[i-1] <= w)
  dp[i][w] = max(dp[i-1][w], value[i-1] + dp[i-1][w-weight[i-1]])
else
  dp[i][w] = dp[i-1][w]

📋 Algorithm Steps

  1. Create dp[n+1][W+1] table
  2. Set dp[0][w] = 0 and dp[i][0] = 0 (base cases)
  3. For each item i, for each capacity w:
  4. If weight[i-1] ≤ w → dp[i][w] = max(skip, take)
  5. Else → dp[i][w] = dp[i-1][w] (can't take it)
  6. Answer is dp[n][W]

💻 Complete Code

01knapsac.c 
#include <stdio.h>

/* Returns the maximum of two integers */
int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    int n, W;

    printf("Enter number of items: ");
    scanf("%d", &n);

    int weight[n], value[n];

    printf("Enter weights:\n");
    for (int i = 0; i < n; i++)
        scanf("%d", &weight[i]);

    printf("Enter values:\n");
    for (int i = 0; i < n; i++)
        scanf("%d", &value[i]);

    printf("Enter capacity: ");
    scanf("%d", &W);

    /* dp[i][w] = max value using first i items with capacity w */
    int dp[n + 1][W + 1];

    /* Fill the DP table bottom-up */
    for (int i = 0; i <= n; i++) {
        for (int w = 0; w <= W; w++) {

            /* Base case: no items or no capacity → value is 0 */
            if (i == 0 || w == 0)
                dp[i][w] = 0;

            /* ⭐ If item fits: choose max of (skip it, take it) */
            else if (weight[i - 1] <= w)
                dp[i][w] = max(dp[i - 1][w],
                               value[i - 1] +
                               dp[i - 1][w - weight[i - 1]]);

            /* Item too heavy: skip it */
            else
                dp[i][w] = dp[i - 1][w];
        }
    }

    printf("Maximum value = %d\n", dp[n][W]);

    return 0;
}

Rod Cutting
Dynamic Programming O(n²)
▼

🧠 Core Concept

Given a rod of length n and prices for each length, find the maximum revenue by cutting the rod optimally.

  • Try all possible first cuts (length 1 to i)
  • For each cut: price[cut] + best value for remaining piece
  • dp[i] = maximum price obtainable from rod of length i

⭐ Most Important Line

dp[i] = max(dp[i], price[j-1] + dp[i-j])
where j goes from 1 to i (try all first-cut lengths)

📋 Algorithm Steps

  1. Set dp[0] = 0 (rod of length 0 has no value)
  2. For each length i = 1 to n:
  3. For each cut j = 1 to i: dp[i] = max(dp[i], price[j-1] + dp[i-j])
  4. Answer = dp[n]

💻 Complete Code

rodcutting.c 
#include <stdio.h>

/* Returns the maximum of two integers */
int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    int n;

    printf("Enter rod length: ");
    scanf("%d", &n);

    int price[n];

    printf("Enter prices for lengths 1 to %d:\n", n);

    for (int i = 0; i < n; i++)
        scanf("%d", &price[i]);

    /* dp[i] = maximum revenue obtainable from rod of length i */
    int dp[n + 1];

    dp[0] = 0;  /* Base case: rod of length 0 → no revenue */

    /* Build up: compute dp[1], dp[2], ... dp[n] */
    for (int i = 1; i <= n; i++) {
        dp[i] = 0;

        /* ⭐ Try every possible first-cut length j (from 1 to i)
           price[j-1] = revenue from the cut piece of length j
           dp[i-j]    = best revenue from the remaining piece */
        for (int j = 1; j <= i; j++) {
            dp[i] = max(dp[i],
                        price[j - 1] + dp[i - j]);
        }
    }

    printf("Maximum revenue = %d\n", dp[n]);

    return 0;
}

LCS — Longest Common Subsequence
Dynamic Programming O(m×n)
▼

🧠 Core Concept

Given two strings, find the longest sequence that appears in both without changing the order of characters.

  • dp[i][j] = LCS length of first i characters of X and first j characters of Y
  • If characters match: extend the LCS from the diagonal
  • If they don't: take the max from left or top cell

⭐ Main Logic — Two Cases

If match: dp[i][j] = dp[i-1][j-1] + 1
If no match: dp[i][j] = max(dp[i-1][j], dp[i][j-1])

📋 Algorithm Steps

  1. Create dp[m+1][n+1] table (m = len(X), n = len(Y))
  2. Set dp[0][j] = 0 and dp[i][0] = 0 (base cases)
  3. For each pair (i, j): if X[i-1] == Y[j-1] → diagonal + 1
  4. Else → max of left and top cell
  5. Answer = dp[m][n]

💻 Complete Code

lcs.c 
#include <stdio.h>
#include <string.h>

/* Returns the maximum of two integers */
int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    char X[100], Y[100];

    printf("Enter first string: ");
    scanf("%s", X);

    printf("Enter second string: ");
    scanf("%s", Y);

    int m = strlen(X);    /* Length of first string */
    int n = strlen(Y);    /* Length of second string */

    /* dp[i][j] = LCS length of X[0..i-1] and Y[0..j-1] */
    int dp[m + 1][n + 1];

    /* Fill the DP table */
    for (int i = 0; i <= m; i++) {
        for (int j = 0; j <= n; j++) {

            /* Base case: empty string → LCS = 0 */
            if (i == 0 || j == 0)
                dp[i][j] = 0;

            /* ⭐ Characters match → extend LCS from diagonal */
            else if (X[i - 1] == Y[j - 1])
                dp[i][j] =
                    dp[i - 1][j - 1] + 1;

            /* Characters don't match → take best from left or top */
            else
                dp[i][j] =
                    max(dp[i - 1][j],
                        dp[i][j - 1]);
        }
    }

    printf("Length of LCS = %d\n", dp[m][n]);

    return 0;
}
